普通编辑默认从 edit(path, changes) 开始。

选择阶梯：
1. 一次精确替换、插入、删除或重复替换，使用 edit()。
2. 同一文件的独立修改放进每个路径只调用一次 edit 的数组，规范 change 形态为
   { find, put, all? }。
3. 只有每一处精确命中都应修改时，才设置 all: true。
4. 需要计算、重排或生成整个文件时，使用 rewrite(path, newText)。

近似匹配只产生诊断，绝不获得写权限。edit() 只有在命中精确、唯一且互不重叠时才暂存修改；
失败的 edit 零暂存，并直接告诉你下一次应引用哪段当前文本。
