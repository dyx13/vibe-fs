# 工具 · review

提交本任的阶段评审，判定离下一里程碑的差距。与 Manager 的 review 共用同一工具名与三问语义；Plan 后端的评审目标是下一里程碑，由当前阶段推出：`S1` 的目标是 `S2`（理解与路径就绪），`S2` 的目标是 `S3`（流程与伪代码就绪），`S3` 的目标是成为最后一任（获得交付授权）。

## 契约与使用

1. **三问**：先形式化目标状态；指出当前与目标的差距；判断差距是否为空集。
2. **findings 对**：`findings` 是 `acceptance_criteria` 与 `work_plan` 组成的对数组。每个非空差距对应一条验收标准（目标状态的形式化）与一条工作计划（弥合差距的做法）。空数组表示差距为空集。
3. **后果**：空集晋级——`S1` 晋级 `S2`、`S2` 晋级 `S3`、`S3` 获得交付授权。非空留任：差距作为修复义务返回，本任留在原阶段。
4. **每任一次**：本任已评后再次调用被强类型拒绝。修复质量由下一任独立评审，不由你自证。
5. **评审对象**：是差距，不是完成度自评。第一任与后任同一标准。
