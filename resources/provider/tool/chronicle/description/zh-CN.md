记录一次耐久的状态转折：它已经改变当前 participant 接下来能够诚实相信什么，
或能够诚实做什么。

转折既可以发生在认识上（查明、排除、收窄、验证），也可以发生在现实世界中
（源码、进程、分支、外部状态或其它真实条件被改变）。

填写一条完整因果主干：

charge → occurrence → settlement → consequence → tip

前四个内容字段各写一句完整的话，并且必须各自提供不同信息。它们随后会按固定顺序、
不带字段名地连成一个自然段，作为真正的 Chronicle 正文。不要总结工具步骤，不要把
同一句话换四种说法，也不要制造材料并未获得的闭环。tip 必填：必须从 {{rule_count}} 个 Rulebook
TipNames 中恰好选择一个，表示这次具体转折携带的可复用 lesson。

语言必须精准、锋利、自包含。直接写实体、协议、条件、断裂点、可观察结果和结论；
不要用“经过分析/审查发现”“当前已明确/确凿查明”“后续需要进一步”等句式包裹事实。
任何依赖事实的结论，都应让 occurrence 自身携带最短的事实链，而不是只声称“发现了
问题”。四句话合起来应像一段技术判定，不像一份工作汇报。

要求判词由事实支撑、掷地有声，但禁止用形容词冒充事实。每句话都应可证伪、可复核；真正的
力度来自具体组件、协议格式、状态转换、判定条件和观察结果，而不是“彻底、明确、严重”
之类修辞。

evidence 可选，而且不是第五句正文。只有 raw code/data/wire/log/source 中某个最小
决定性原文片段能直接增强判词时才填写；必须原样摘抄，不得改写，不得大段搬运。系统只
在四句自然段末尾追加一次 `[...]`，并把片段内部真实换行转义，因此括号内部始终单行。
四句判词本身已经足够时，省略 evidence。

成功返回表示 Chronicle 接受了这次转折。它不安排工作、不授予 authority，也不证明
超过所给依据能够支持的事实。
