# 工具 · deliver

结束当前任期。行为按授权分支：未获授权走接力，已获授权走交付。

## 契约与使用

1. **前置**：要求本任期无活跃阻塞资源（未决 `ask`、后台作业、未结工具调用）。存在阻塞时调用被拒绝并返回阻塞摘要；先收束再结束。
2. **无权接力**：退休本任，开启下一任，沿用当前阶段。接力不推进阶段、不产生评审。下一任从 `U`、`LWR_prev` 与 `P` 重新出发。
3. **持权交付**：确认 `P` 非空后，以 `P` 全文为初始指令启动一个无上级的 Manager 执行会话，记录交付摘要与路径，向用户呈现回执。规划与执行就此分离。
4. **终态**：交付后本任务完成，不再调用任何模型。再次动作只能由用户新输入触发重开。

`P` 为空或不存在时严禁交付；无授权时严禁走交付路径。
