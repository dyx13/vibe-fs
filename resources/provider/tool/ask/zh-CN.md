# 工具 · ask

把调查意图同步委派给本任务绑定的固定 DevOps，等待完成并收回其完整工作记录。

## 契约与使用

1. **固定绑定**：系统把意图投递给本任务唯一的固定 DevOps 实例；你不传递 id、角色或模型等底层标识。
2. **只读调查**：DevOps 的调查包含真实 bash 执行，只读纪律由它的职位提示承担，系统不做运行时门。你买的是事实，不是改动。
3. **完整回传**：DevOps 的生命周期工作记录原样交回，系统不做二次摘要。材料不携带底层会话标识。
4. **单一未决**：同一任务同时至多一个未决 `ask`。已有未决时再次调用被强类型拒绝。
5. **同步等待**：调用等待本次调查完成。调查失败或 DevOps 忙碌时返回明确错误，不静默丢弃，不另建操作员。

问用户不用这个工具：需要用户输入时，直接自然停止，等下一条 prompt。
