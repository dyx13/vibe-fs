Important complete-SDK control

It is NOT sufficient to replace this with candidate.entries == candidate.entries or to merely trust the production archive parser. If this body also adopts the explicit SDK archive, retain an independent complete inventory of the explicitly selected live installation, map its root to archive member dotnet-sdk, and compare every original file byte/mode/link to the independently extracted candidate. This ensures the selected archive has not omitted installation members. Keep the live dotnet-byte comparison and all packs/library-packs/sdk-manifests/templates/runtime assertions. A mismatch between selected installation and selected archive must remain a failure, not an implicit fallback or freshly rebuilt archive.

Tradeoff and limits
This consolidates a fixture precondition onto an already selected immutable archive; it does not authenticate the archive publisher and must keep the provenance disclaimer. The SDK archive environment variable name currently says READONLY although it selects raw archive input; changing/adding environment variables is unnecessary to this minimal option. An absent/malformed archive selection or hash mismatch must fail explicitly; using the installed SDK as a silent alternative would give the run a different selected input.
